# Expense Tracker 💰

A full-stack Expense Tracker application designed to help users track, manage, and analyze their daily finances efficiently.

## 🚀 Features

* **Expense & Income Tracking:** Easily record daily transactions with categories, amounts, and dates.
* **Dashboard Analytics:** Visual breakdown of spending habits and financial summaries.
* **Responsive UI:** Modern, clean, and mobile-friendly interface.
* **RESTful API Backend:** Python backend for managing persistent financial data.

## 🛠️ Tech Stack

* **Frontend:** TypeScript, React, Vite, Tailwind CSS
* **Backend:** Python, FastAPI
* **Package Management:** pnpm, uv
* **Development/Deployment:** Replit, Node.js

## 📂 Project Structure

```text
Expense-Tracker/
├── .agents/          # Replit agent configuration & memory
├── artifacts/        # Build artifacts and static assets
├── lib/              # Client libraries & API utility code

├── main.py           # Backend entry point

```

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed locally:

* Node.js v18 or higher
* pnpm
* Python v3.10 or higher
* uv

### Installation & Setup

#### 1. Clone the Repository

```bash
git clone https://github.com/vishwas-78/Expense-Tracker.git
cd Expense-Tracker
```

#### 2. Install Frontend Dependencies

```bash
pnpm install
```

#### 3. Install Backend Dependencies

```bash
uv sync
```

#### 4. Run the Backend

```bash
python main.py
```

#### 5. Run the Frontend

```bash
pnpm dev
```
